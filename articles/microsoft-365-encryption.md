# Microsoft 365 encryption: historical review

The 2025 coursework project studied multiple protection layers in a cloud productivity service: data encryption, transport protection, identity controls, key management and digital-signature mechanisms.

The analysis used an Extended CIA framing to consider what each layer protects, the assumptions it depends on and remaining organisational/operational risks. The project also reviewed cryptography-industry development in Australia.

This is an outline of the original research scope. It does not provide verified current product specifications. Before extending the article, recover the original reference list, verify each claim against primary documentation and label the research date.
